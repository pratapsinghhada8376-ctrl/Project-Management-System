
# Project Management System

A Java Swing based desktop application developed to manage projects efficiently.

## Project Information
- **Project Name:** Project Management System
- **Developed By:** Pratap Singh Hada
- **Course:** B.Tech CSE
- **College:** Poornima Institute of Engineering and Technology (PIET)

## Technologies Used
- Java
- Java Swing
- Java AWT
- MySQL
- IntelliJ IDEA

## Features
- User Login
- Dashboard
- Create New Project
- View Project
- Edit Project
- Delete Project
- Change Password

## Project Structure
```text
Project-Management-System/
└── src/
    ├── Login.java
    ├── Dashboard.java
    ├── DBConnection.java
    ├── newproject.java
    ├── projects.java
    ├── ViewProject.java
    ├── EditProject.java
    └── DeleteProject.java
```

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Configure the MySQL database connection.
4. Set the DB_PASSWORD environment variable.
5. Run the Login or Main class.
